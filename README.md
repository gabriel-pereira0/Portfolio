# 💼 Portfólio Pessoal

Portfólio desenvolvido para apresentar minha trajetória de aprendizado, projetos desenvolvidos e tecnologias estudadas durante minha evolução na área de desenvolvimento web.

O projeto foi criado com foco em uma interface moderna, responsiva e intuitiva, reunindo informações sobre minhas habilidades, experiências, projetos e formas de contato.

## 🌐 Projeto Online

👉 **Acesse o portfólio:** [Link do projeto]

## ✨ Funcionalidades

- Apresentação pessoal e trajetória profissional;
- Seção de tecnologias e conhecimentos adquiridos;
- Exibição de projetos desenvolvidos com suas respectivas informações;
- Links para repositórios e demonstrações dos projetos;
- Navegação dinâmica entre seções;
- Layout responsivo para diferentes dispositivos;
- Seção de contato para facilitar a comunicação.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git

## 📚 Objetivo do projeto

Este projeto foi desenvolvido com o objetivo de criar uma apresentação profissional das minhas habilidades em desenvolvimento web, aplicando conceitos de estruturação HTML, estilização CSS, manipulação com JavaScript e boas práticas de organização de código.

Além disso, o portfólio representa minha evolução durante os estudos de Front-end, reunindo projetos práticos desenvolvidos ao longo da minha jornada de aprendizado.
